### Open-Source AI Agents — THQ.Digital

Production agents I helped build and open-source. All Apache 2.0, self-hostable, no vendor lock-in.

| Agent | What it does |
|---|---|
| **[VerifyAgent](https://github.com/clarity2cloud/Verify-Agent)** | Deterministic document verification — 8-stage pipeline (OCR → classification → cross-document matching → fraud detection → risk scoring → AI audit), 25+ Indian document types, offline face matching. |
| **[SmartRFP](https://github.com/clarity2cloud/Smartrfp)** | Upload an RFP, get a compliant draft response in minutes. Parses PDF/DOCX, extracts every requirement via LLM, answers grounded in your own knowledge base via RAG. |
| **[ContentStudio](https://github.com/clarity2cloud/ContentStudio)** | One topic in, channel-native content out — blog, LinkedIn, Instagram, X, email — all aligned to a single brand voice, in one API call. |
| **[PitchCraft](https://github.com/clarity2cloud/Pitchcraft)** | Branded, client-ready proposals from a prompt. Tone control, AI-assisted section rewriting, shareable client links with view tracking. |
